Reading this view

Colour shows when a service is hit, not how risky it is. Each node is also labelled with its hop.

  • hop 0 — the service you knocked out
  • hop 1 — depends directly on it, fails first
  • hop 2 — knocked out one step later
  • hop 3+ — the far edge of the blast radius
  • grey — unaffected, dimmed during a run

Node size is incoming call volume, so a large red node means a lot of traffic just died. Red links trace the path the failure travelled.
